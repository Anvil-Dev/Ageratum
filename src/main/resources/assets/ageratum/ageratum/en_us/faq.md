# Frequently Asked Questions

## What is Ageratum?

Ageratum is a documentation/guide framework designed for Minecraft mod developers and players.

## What formats does it support?

It supports full CommonMark Markdown format, plus some extensions like:
- Custom color tags
- Hover and click events
- Tip box containers
- Tables

## How do I create my own guide?

1. Create `assets/<namespace>/ageratum/<lang>/` in your resource pack
2. Add `.md` files
3. Use `/ageratum <namespace>` to open

## What languages are supported?

Default support for English (`en_us`) and Simplified Chinese (`zh_cn`).

You can add other languages in your resource pack, like `pt_br/`, `es_es/`, etc.

## Does it cause lag?

No. Documents are parsed once on load, then rendered components are displayed directly.

## What can I use it for?

- Create mod documentation
- Write tutorials
- Document APIs
- Create game guides
