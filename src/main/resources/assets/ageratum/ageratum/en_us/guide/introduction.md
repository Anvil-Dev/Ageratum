# Complete Markdown Guide

This document covers all Markdown syntax supported by Ageratum.

## Headings

# Level 1 Heading
## Level 2 Heading
### Level 3 Heading

## Text Styles

This is **bold** and *italic* and ~~strikethrough~~.

You can also use __bold__ or _italic_.

## Lists

### Unordered List

- Item 1
- Item 2
  - Nested item 2.1
  - Nested item 2.2
- Item 3

### Ordered List

1. First item
2. Second item
   1. Nested item 2.1
   2. Nested item 2.2
3. Third item

### Task List

- [x] Completed task
- [ ] Incomplete task
- [x] Another completed task
