# Simple Example

## Minimal Guide

This is a minimal example of creating an Ageratum guide.

### File Structure

```
src/main/resources/
└── assets/
    └── mymod/
        └── ageratum/
            └── en_us/
                └── index.md
```

### index.md Content

```markdown
# My Mod

This is a simple mod guide.

## Features

- Feature 1
- Feature 2
- Feature 3

## Installation

1. Download JAR
2. Place in mods folder
3. Start game

Done!
```

### Open the Guide

```
/ageratum mymod
```

## That's It!

Creating an Ageratum guide only requires:
1. Creating the folder structure
2. Adding Markdown files
3. Using the command to open

No configuration, no programming needed!
