# Getting Started

Welcome to Ageratum! This guide will help you get started quickly.

## Installation

1. Download the latest version of Ageratum
2. Place the JAR file in your mods folder
3. Launch Minecraft

## Basic Usage

### Opening Guides

Use the command `/ageratum ageratum` to open this guide.

You can use `/ageratum <namespace>` to open guides for other mods.

### Navigation

- The left sidebar shows all available pages
- Click a page to jump to it
- Use mouse wheel or arrow keys to scroll

## FAQ

Q: How do I create my own guide?

A: Create a file at `assets/<namespace>/ageratum/<lang>/index.md` in your resource pack and write content in Markdown format.
