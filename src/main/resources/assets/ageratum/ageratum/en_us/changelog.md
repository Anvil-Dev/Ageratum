# Changelog

## Version 0.0.1

### New Features

- ✨ Complete Markdown support
  - ATX and Setext headings
  - Unordered, ordered, and task lists
  - Code blocks and inline code
  - Tables
  - Blockquotes
  - Images (using resource locations)

- ✨ Interactive features
  - Scrollable sidebar (two-level navigation)
  - Hover and click events
  - Cross-document link jumping
  - Anchor navigation support

- ✨ Extension system
  - Custom component registration
  - Tip box containers (info, tip, warning, danger)
  - Hover and click event tags

- ✨ Internationalization
  - Multi-language support (en_us, zh_cn)
  - Automatic language fallback

### Improvements

- Full-line scroll alignment (sidebar doesn't show half-lines)
- Scroll indicator arrows (fade-in effect)
- Document title priority: front matter > H1 > filename
- Path grouping and sorting: index first, then dictionary order

### Bug Fixes

- Fixed sidebar mouse range detection
