# 简单示例

## 最小化的指南

这是创建 Ageratum 指南的最小示例。

### 文件结构

```
src/main/resources/
└── assets/
    └── mymod/
        └── ageratum/
            └── zh_cn/
                └── index.md
```

### index.md 内容

```markdown
# 我的模组

这是一个简单的模组指南。

## 功能

- 功能 1
- 功能 2
- 功能 3

## 安装

1. 下载 JAR
2. 放入 mods 文件夹
3. 启动游戏

完成！
```

### 打开指南

```
/ageratum mymod
```

## 就这么简单

创建 Ageratum 指南只需要：
1. 创建文件夹结构
2. 添加 Markdown 文件
3. 使用命令打开

无需配置，无需编程！
