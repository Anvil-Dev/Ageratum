# 更新日志

## 版本 0.0.1

### 新增功能

- ✨ 完整的 Markdown 支持
  - ATX 和 Setext 标题
  - 无序、有序和任务列表
  - 代码块和行内代码
  - 表格
  - 引用块
  - 图片（使用资源位置）

- ✨ 交互功能
  - 可滚动的侧边栏（两级导航）
  - 鼠标悬停和点击事件
  - 跨文档链接跳转
  - 锚点导航支持

- ✨ 扩展系统
  - 自定义组件注册
  - 提示框容器（info、tip、warning、danger）
  - 悬停提示和点击事件标签

- ✨ 国际化
  - 多语言支持（en_us、zh_cn）
  - 自动语言回退

### 改进

- 整行滚动对齐（侧栏不显示半行标签）
- 滚动指示箭头（淡入效果）
- 文档标题优先级：front matter > H1 > 文件名
- 路径分组排序：index 优先，其次字典序

### Bug 修复

- 固定侧栏鼠标范围检测
